# gateway_rt

## Functions

- [load_config](load_config.md) — Load config from an explicit path or fall back to built-in defaults.
- [probe_gateway](probe_gateway.md) — Minimal gateway liveness probe used by `doctor` and the UI status command.
- [run_headless](run_headless.md) — Run the gateway on the calling thread (foreground / headless service mode).
- [spawn_background](spawn_background.md) — Spawn the gateway on a background thread; returns immediately.
